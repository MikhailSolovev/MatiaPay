# MatiaPay

Payments authorised by facial recognition.

## Layout

- `app/` — source code (empty so far).
- `product/` — product management docs: vision, strategy, discovery, requirements, roadmap, compliance, metrics, decisions, releases. Start at `product/README.md`.

## Working rules

- Face data is biometric data. Any change to face capture, matching, storage or payment authorisation must be checked against `product/compliance/biometric-privacy-and-risk.md`.
- Feature specs go in `product/requirements/`, one PRD per feature.
- Non-obvious product decisions are logged in `product/decisions/`.
